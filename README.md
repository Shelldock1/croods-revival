# The Croods 1.3.1 — запуск без серверов Rovio

Игра The Croods (Rovio, 2013) для Android больше не запускается: она требует вход через сервер
`cloud.rovio.com`, а этот сервер давно отключён и отвечает «No such API». Оригинальный APK
показывает «Connection error: This game requires an Internet connection» и дальше заставки не идёт.

В этом репозитории лежат **патчер**, который делает из оригинального APK версию для офлайн-игры, и
маленький **сервер-заменитель**, который запускается на твоём компьютере и отвечает игре вместо Rovio.

> ⚠️ **Самой игры здесь нет.** APK The Croods (© Rovio / DreamWorks) в репозиторий не входит:
> нужен свой файл `the_croods_1.3.1.apk` (Android, версия 1.3.1), из него скрипт соберёт
> `croods_offline.apk` (см. «Сборка игры»).
>
> Неофициальный некоммерческий проект для сохранения и изучения игры, не связан с Rovio и DreamWorks.
> Используя его, вы принимаете условия [отказа от ответственности](DISCLAIMER.md).

## Сборка игры (один раз)

1. Положи свой APK The Croods 1.3.1 в папку `original/` под именем `the_croods_1.3.1.apk`.
   Подходит только этот файл (SHA-256
   `2f754150addfb7c7d900c6dcdb3f0849c95f60b980f1863b5c35ded9b0653801`) — патчер проверяет байты
   и с другой версией остановится с ошибкой.
2. Собери `croods_offline.apk`:
   - **Windows** (нужны Python и Android Studio из шагов ниже): двойной щелчок по `tools\build_apk.bat`;
   - **Linux** (после `tools/setup_emulator_linux.sh`): `tools/build_apk.sh`.

Готовый `croods_offline.apk` появится в корне репозитория.

## Быстрый старт на Linux

Нужно примерно 3 ГБ на диске. Права администратора (sudo) не нужны.

1. **Python-библиотека для сервера** (один раз):
   ```bash
   python3 -m pip install --user cryptography
   ```
   (на Ubuntu можно и так: `sudo apt install python3-cryptography`)

2. **Эмулятор Android** (один раз). Скрипт сам скачает Java, Android SDK и образ Android 9 в `~/Android`
   и создаст виртуальный телефон `Croods_API28`. Запуская его, ты принимаешь
   [лицензию Android SDK](https://developer.android.com/studio/terms):
   ```bash
   tools/setup_emulator_linux.sh
   ```

3. **Запустить эмулятор** и дождаться рабочего стола Android:
   ```bash
   ~/Android/Sdk/emulator/emulator -avd Croods_API28 -gpu swiftshader_indirect
   ```

4. **Установить игру** (один раз; сначала собери её — см. «Сборка игры»):
   ```bash
   ~/Android/Sdk/platform-tools/adb install -r croods_offline.apk
   ```
   Если стоит оригинальная The Croods — сначала удали её: `adb uninstall com.rovio.croods`.

5. **Запустить сервер** в отдельном окне терминала и не закрывать его, пока играешь:
   ```bash
   ./run_server.sh
   ```

6. В эмуляторе открыть **The Croods**. На предупреждение «This app was built for an older version
   of Android» нажать OK. В меню нажать большую жёлтую кнопку ▶.

### Окно «Приложение Emulator не отвечает» (GNOME)

Это не вылет игры. Эмулятор рисует графику процессором, и иногда не успевает ответить на проверку GNOME.
**Нажимай «Подождать»**, не «Принудительно завершить» — иначе эмулятор закроется.
Чтобы окно не появлялось, увеличь время проверки до 60 секунд:
```bash
gsettings set org.gnome.mutter check-alive-timeout 60000
```
Вернуть как было: `gsettings reset org.gnome.mutter check-alive-timeout`.

## Быстрый старт на Windows

> `run_server.bat` сам находит установленный Python и ставит `cryptography`, если её нет.
> Если игра показывает чёрный экран, в настройках виртуального телефона выбери *Graphics: Software*.
> Вспомогательные скрипты: `play_with_log.bat` — запустить игру и писать журнал в `logcat.txt`
> (ошибки Lua — строки `LUAERR`), `restart_game.bat` — новая игра с нуля, `save_logcat.bat` — сохранить журнал.

1. **Python 3**: скачать с [python.org](https://www.python.org/downloads/), при установке
   поставить галочку **«Add python.exe to PATH»**. Потом в «Командной строке» (cmd):
   ```bat
   pip install cryptography
   ```

2. **Android Studio**: скачать с [developer.android.com/studio](https://developer.android.com/studio)
   и установить с настройками по умолчанию (он сам поставит эмулятор и включит ускорение).

3. **Создать виртуальный телефон**: в Android Studio → *More Actions* → *Virtual Device Manager* →
   *Create Device* (+) → **Pixel 2** → Next → вкладка *x86 Images* (или *Other Images*) →
   **Pie, API 28, x86, Android 9.0** (без «Google Play») → скачать → Next → Finish.
   В настройках устройства (*Show Advanced Settings*) можно выставить *Graphics: Software*,
   если с аппаратной графикой игра вылетает.

4. **Запустить эмулятор** кнопкой ▶ в Device Manager и дождаться рабочего стола Android.

5. **Собрать и установить игру**: собрать `croods_offline.apk` (см. «Сборка игры») и перетащить его
   мышкой в окно эмулятора.

6. **Запустить сервер**: двойной щелчок по `run_server.bat`. Окно должно остаться открытым.
   Если Windows спросит про брандмауэр — можно отказать (сервер работает только внутри компьютера).

7. В эмуляторе открыть **The Croods**, на предупреждение нажать OK, в меню — жёлтую кнопку ▶.

> Работает только в **эмуляторе Android Studio**: игра ищет сервер по адресу `10.0.2.2`,
> который есть только там. BlueStacks, LDPlayer, Nox и настоящий телефон не подойдут
> (для них нужно пересобрать APK с другим адресом, см. ниже).

## Что было сделано

1. **Разобрали APK.** Игра 2013 года (Android 4.0, только 32-битный код). Вся логика — на Lua,
   скрипты зашифрованы. Сетевой код — в нативной библиотеке `libCroods.so`.
2. **Подменили адрес сервера.** В `libCroods.so` строки `https://cloud.rovio.com` и
   `http://cloud.rovio.com` заменены на `http://10.0.2.2:8000` (это компьютер, видимый из эмулятора).
   APK переподписан своим ключом (`debug.keystore`, пароль `android`).
3. **Включили вывод ошибок и убрали вылет.** Раньше при ошибке Lua игра молча падала с «Lua error!
   Crashing app...». В x86-библиотеке пропатчен обработчик в `GameLua::update`: в журнал Android
   пишется сам текст ошибки (`LUAERR: ...`), а вместо `std::terminate()` кадр просто завершается, и
   игра идёт дальше (окно, в котором случилась ошибка, может не открыться — но приложение не закрывается).
4. **Написали сервер-заменитель** (`server/fake_rovio.py`). Формат ответов восстановлен по коду игры:
   вход (`/identity/2.0/access`), список служб (`/identity/2.0/config`), гостевой аккаунт, профиль,
   время, сохранение и загрузка «ассетов».
5. **Расшифровали скрипты** (AES-256-CBC → архив 7z → байт-код Lua 5.1) и декомпилировали их.
   Ключи найдены в `libCroods.so`.
6. **Восстановили таблицы экономики.** Игра при каждом запуске скачивает с сервера 21 CSV-таблицу
   (существа, загоны, ловушки, уровни, задания...) и Lua-файлы `IAP` и `alerts`. Их нет нигде, поэтому
   колонки взяты из кода игры, значения — из дампа объектов и отчётов игроков 2013 года, а недостающие
   подобраны по тем же правилам (см. «Баланс экономики»). Сервер отдаёт их зашифрованными тем же
   ключом, что ждёт игра.
7. **Сделали «стенд» для отладки** (`tools/harness.py`): игровая логика запускается прямо на компьютере
   с заглушками вместо движка, и любая ошибка показывает точную цепочку вызовов. Так нашлись почти все
   недостающие данные.

## Известные проблемы

1. **Вылеты в обучении** (все найденные — исправлены):
   - `TrapObject.initialize > 'for' limit must be a number` — колонка `currencies` в `traps.csv` — это
     число, а не название ресурса.
   - `LockToWorldContextMenu.initialize > attempt to index field 'target'` — сразу после установки
     первой ловушки обучение открывает её меню и ищет кнопку «улучшить», которая есть только у
     достроенной ловушки. Шаг «ускорить кристаллами» перед ним ищет кнопку по картинке, которой в игре
     нет, и пропускается. Поэтому первая ловушка (`Trap_Molerbear`) теперь строится мгновенно
     (`constructTime = 0`).
   - `QuestCharacter.showQuestIndicator > attempt to index a nil value` — задания выдаются сразу для всех
     уровней ≤ уровня игрока. Обучение само строит ловушку и дом, ловит и приручает зверя, а значки над
     персонажами в это время запрещены — выполненное задание роняло игру. Задания теперь начинаются с
     3-го уровня (за обучение набирается меньше 150 опыта).
   - `ResourceManager.getRovioAmountForResources > attempt to index field '?'` — вылет при нажатии на
     Уггу после диалога (и сразу при загрузке такого сохранения). Цена «пропустить ожидание рецепта»
     считается как `минуты × ConvertRovio` ресурса `Time`, а строки `Time` в
     `resourceconversiontable.csv` не было. Добавлена (0,1 кристалла за минуту).
   - Тунк: в `miscValues.csv` не было `THUNK_REWARD_ROVIOS`, `THUNK_RESPAWN_TIME_MIN/MAX` —
     `math.random(nil, nil)` уронил бы игру при первой награде Тунка. Добавлены (3 кристалла, 4–8 часов).
   - На случай ещё не найденных пропусков в данных стоит защита от вылетов (см. «Что было сделано», п. 3).
     **Для неё нужно переустановить `croods_offline.apk`** (прогресс сохранится: ключ подписи тот же).
2. **Сохранения.** Раньше сервер игнорировал запись (`POST /storage/state`), и игра считала это
   ошибкой связи («Connection error» прямо во время игры), а при запуске всегда начинала заново. Теперь
   сервер хранит сохранения в `server/saves.json`. Чтобы начать игру заново, удали этот файл и запусти
   `restart_game.bat` (Windows).
3. **Баланс восстановлен частично**: точные цифры сохранились только для части таблиц, остальное
   подобрано по правилам игры (подробности — в разделе «Баланс экономики»).
4. Магазин за реальные деньги, Facebook и реклама не работают (их серверов нет). Поэтому кристаллы
   (Rovios) в офлайн-версии можно получить только за уровни игрока и за расчистку камней и деревьев.

## Баланс экономики

Все таблицы лежат в `tools/economy_data.py` и генерируются в `server/assets/` командой
`python3 tools/gen_assets.py`. Ниже — что взято из самой игры, а что оценено.

### Взято из игры (дамп объектов и байт-код)

- **Пища и продукт каждого существа** — из `GameObjects.lua` (`feedCurrency` / `outputResource`).
  Цепочка еды: Molerbear (ягоды → морковь), Girelephant (морковь → листья), Bunny Beast
  (морковь → камни), Crocopup (морковь → кости), Ramu (кости → яйца), Albatroceros (ягоды → перья),
  Bear Owl (ягоды → монеты), Sharkodile (кости → рыба), Fish Cat (рыба → грязь), Zeaver (ягоды → палки),
  Liyote (яйца → фрукты), Land Whale (морковь → монеты).
- **Цикл производства жилища — 5 минут** (`productionTime=5`); одно кормление даёт 3 цикла по
  1 единице, а `productionCap` — это склад (16/24/32, у «монетных» зверей 50/75/100).
- **Соотношения корма и продукта**: Molerbear 1:1, Girelephant/Crocopup/Zeaver 3:1, Bunny Beast/Ramu/
  Sharkodile 2:1, Bear Owl 2 ягоды → 5 монет — ровно как в цепочке обмена ниже.
- **Время постройки ловушек — 4 минуты** (кроме первой, см. известные проблемы).
- **Формулы**: опыт существа = `feedingSessions × Σ feedPerSession` (поэтому кормление 3 раза =
  приручение); ускорение производства = `(уровень−2)×productionTimeDecrease + playBoost + cleanBoost`,
  все коэффициенты — доли, а не проценты.
- **Приручение — 3 кормления**, любимое украшение — череп (`SKULL_01`), +5 % за каждое.
- **Уровень 21 — 100 кристаллов**; стартовые запасы и таймер обновления заданий Угги.
- **Ёмкость пещеры**: 50 на 1-м уровне, 75 на 2-м, дальше +25.

### Взято из образца сохранения внутри игры (`BeltsMap.lua`, мир «Friendly Neighbor»)

- Таймер нового рецепта Угги — 300 с (`SINK_QUEST_RENEW_TIMER = 5` минут).
- Цена ресурсов у Угги: «4 моркови → 12 монет», «5 ягод → 5 монет», т.е. морковь стоит 3, ягода 1.
- Достижения: 6 полностью (название, тип, цель, номер), ещё 12 — только названия и номера;
  их цели придуманы по названиям.
- Сколько домов можно построить: у игрока 18-го уровня до 8 домов Molerbear и 5 Bunny Beast. Поэтому
  после открытия зверя каждые 3 уровня даётся ещё один дом (не больше 8).

### Взято из отчётов игроков 2013 года (одиночные источники)

- Zeaver home — 32 400 монет и 192 часа постройки; Fish Cat home 2-го уровня — 24 300 монет;
  Bear Owl home — только кристаллы, 1 ч 45 мин; Land Whale — 1000 монет, апгрейд 7875 монет + 5 палок.
- Куст ягод: ёмкость 24 на 2-м уровне, 38 на 3-м, апгрейды за 50 и 100 кристаллов.
- Большое дерево — 20 опыта + 3 кристалла, большой камень — 40 опыта + 4 кристалла.
- Обмен ресурсов: 54 ягоды → 54 моркови → 18 листьев → 6 костей → 3 рыбы → 1 палка
  (отсюда таблица `resourceconversiontable.csv`).

### Оценено (правила, по которым считалось)

- Цены домов: круглые числа × степени тройки (100 → 300 → 900 → 2700 → 8100 → 24 300 → 32 400).
  Апгрейды — ×3 и ×9 от цены дома.
- Ловушки стоят вдвое дешевле дома и улучшаются едой существа и палками; шансы поимки
  25 / 50 / 75 / 100 %, время ожидания 5–27 минут.
- Награды за задания существ ≈ половина цены дома (по 1/10 за шаг), поэтому постройка не «бесплатна».
- Опыт уровней игрока: `25 × уровень × (уровень+1)`; награды монетами `50 × уровень`.
- Существа открываются на уровнях 1, 3, 5, … 23, задания — на два уровня позже.
- `sinkquestdefinitions.csv` (суп Угги) — 2–17 единиц каждого ресурса по уровню; монеты,
  кристаллы, опыт и суп оставлены нулями, чтобы они не попадали в список ингредиентов.

### Если хочется играть быстрее

Правь числа в `tools/economy_data.py` и перегенерируй ассеты. Самые «дорогие» места:
`HABITAT_ROWS` (цены и время постройки, у Zeaver — 8 суток), `cave_levels()` (апгрейды пещеры
до 121 500 монет) и `TRAP_COINS`.

## Как чинить дальше

### 1. Увидеть ошибку
Linux (сбросит прогресс и запустит игру заново):
```bash
tools/dev/restart_game.sh
```
Или вручную: `adb logcat -v raw | grep LUAERR`.

### 2. Узнать, где именно ошибка
Скрипты собраны без номеров строк, поэтому ошибка выглядит как `?:0: attempt to ...`.
Включи «трассировку» — тогда к ошибке добавится цепочка вызовов вида
`GM.TrapObject.initialize > ...`:
```bash
TRACE=1 python3 tools/gen_assets.py
```
(сервер перезапускать не нужно, достаточно перезапустить игру). Выключить: `python3 tools/gen_assets.py`.

### 3. Прочитать код игры
```bash
tools/dev/decompile.sh
```
Скрипты появятся в `work/src` (читаемый Lua) и `work/lua` (байт-код). Ищи функцию из цепочки, например
`grep -n "initialize" work/src/data/scripts/TrapObject.lua`.

### 4. Поменять данные
Все таблицы задаются в **`tools/economy_data.py`** (там же комментарии). После правки:
```bash
python3 tools/gen_assets.py
```
Файлы появятся в `server/assets/`, сервер подхватит их сразу. Колонки каждой таблицы описаны в
`tools/schema.json` (взяты из `TweakValues.lua` игры).

### 5. Проверить без эмулятора (быстро)
```bash
python3 -m pip install --target work/pylib lupa
tools/dev/harness.sh
```
Покажет `--- newgame: ok` или ошибку с цепочкой вызовов. Этапы: загрузка скриптов → меню →
новая игра → 300 кадров. Ошибки на этапе `frames` про графику/камеру — обычно ограничения стенда,
а не игры.

### 6. Пересобрать APK
Нужно, если меняется адрес сервера (например, для BlueStacks или телефона в той же Wi-Fi сети):
поменять `NEW_URL` в `tools/patch_apk.py` (не длиннее 22 символов) и запустить
```bash
tools/build_apk.sh
```
(нужны build-tools из Android SDK; на Linux их ставит `setup_emulator_linux.sh`).
На Windows: `tools\build_apk.bat` (берёт build-tools и Java из установленного Android Studio).
Для телефона ещё потребуется, чтобы сервер слушал не `127.0.0.1`, а адрес компьютера в сети
(последняя строка `server/fake_rovio.py`), и телефон с поддержкой 32-битных приложений.
